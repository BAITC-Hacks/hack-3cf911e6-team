# HackAlem AI (репетиция) — трек «Агентные системы»

Два лёгких кейса: **классификатор обращений** и **фильтр алертов**.
Python 3.8+, только стандартная библиотека — ставить ничего не нужно.

## Как запустить

```bash
git clone https://github.com/BAITC-Hacks/hack-3cf911e6-team.git
cd hack-3cf911e6-team

python classify_messages.py     # кейс 1  (Windows: py classify_messages.py)
python filter_alerts.py         # кейс 2
python selftest.py              # 22 автопроверки, ожидается OK
```

Каждый скрипт принимает свой файл: `python filter_alerts.py other.json`.
Если в `cmd.exe` кириллица выводится квадратами — выполните `chcp 65001`.

## Что получилось

**Кейс 1.** `classify_messages.py` читает `messages.txt` (5 обращений) и печатает для
каждого категорию, сработавшие сигналы и один черновик ответа на русском. Рубрика:
`справка` — просят информацию или документ, `жалоба` — сообщают о проблеме, `другое` —
запись на приём и предложения. Результат: **справка — №1, №5; жалоба — №2, №4; другое — №3.**

Категория — сумма весов сработавших маркеров, а не первое совпадение: в «подскажите, где
получить справку, а то очередь» главный интент — справка. Отрыв меньше 2 баллов даёт
пометку «низкая уверенность», такие обращения выводятся списком на ручную проверку.
Черновик выбирается по паре (категория, тема): жалоба + «ит» → ответ про заявку в ИТ-службу.

**Кейс 2.** `filter_alerts.py` читает `events.json` (8 событий) и печатает три строки
`critical` и итог `критичных 3`.

Задание разрешало определять категорию одним вызовом LLM — мы выбрали правила, чтобы
решение запускалось без ключей и сети. Сроки и подразделения в шаблонах ответов —
заглушки под регламент конкретного вуза.
